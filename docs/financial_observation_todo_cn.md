## 验收标准

1. 金融工作空间可见且可编辑，不影响同花顺和 Agent 技术调研工作空间。
2. 至少有可验证的实际指数序列与官方宏观资料；机构观点按实际获取情况标明，不补造。
3. 数值变化可复算；观察期、数据日期、抓取日期明确；来源失败不能标记成完整成功。
4. 中文报告回答“发生什么、与我的关注有什么关系、哪些解释待验证”，并生成 HTML。
5. 追问引用同一报告快照；最新数据与旧报告不混用。
6. Trace 有请求/画像、采集和质量、计算、分析、发布产物等证据，模型分析不冒充确定性校验。
7. 定时采集可查询运行状态、暂停和恢复；凭证不进报告或 Trace。
8. 审查发现的问题修复后有复测证据；未解决限制明确记录，不把有限测试称为无任何问题。
