# Recorded Fork And Fresh Replay Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 明确区分 Trace/Checkpoint Inspect 与真正 Replay，并实现 Recorded、Fork、Fresh 三种可验证重放以及结构化 ReplayDiff。

**Architecture:** Replay 从经过 checksum 验证的 Checkpoint 开始；Recorded 模式使用录制的 Model/Tool 输出重新执行状态转换、Gate 和 Artifact 构建；Fork/Fresh 创建新 Run，默认使用 Shadow ArtifactStore 和禁写 MemoryPolicy；Diff 对 Context、Prompt、模型、工具、Gate、Memory Proposal、Artifact 和指标逐层比较。

**Tech Stack:** Python 3.10+、Pydantic v2、现有 ExecutorRegistry、EventStore、CheckpointRepository、ArtifactStore、SQLite、pytest。

## Global Constraints

- L0 Trace Inspect 和 L1 Checkpoint Inspect 不能命名为 Replay。
- Recorded Replay 禁止网络、真实工具 handler、Memory 写入和真实副作用。
- Fork/Fresh 必须创建新 Run，不修改原 Run、Event、Artifact 或 Checkpoint。
- 默认使用 Shadow ArtifactStore 和 `MemoryPolicy=deny_write`。
- Checkpoint checksum、版本和依赖不匹配时 fail closed。
- Replay 结果必须产生 Artifact 和结构化 Diff，不能只返回“成功”。

```python
class ReplayMode(str, Enum):
    RECORDED = "recorded"
    FORK = "fork"
    FRESH = "fresh"


class ReplayRequest(BaseModel):
    source_run_id: str
    checkpoint_id: str
    mode: ReplayMode
    prompt_version_override: str | None = None
    policy_version_override: str | None = None
    model_id_override: str | None = None
    resume_task_override: str | None = None
    confirm_external_calls: bool = False

    @model_validator(mode="after")
    def validate_overrides(self):
        if self.mode is ReplayMode.RECORDED and any(
            (self.prompt_version_override, self.policy_version_override, self.model_id_override)
        ):
            raise ValueError("recorded replay does not accept version overrides")
        if self.mode is ReplayMode.FRESH and not self.confirm_external_calls:
            raise ValueError("fresh replay requires confirm_external_calls=true")
        if self.mode is not ReplayMode.FRESH and self.confirm_external_calls:
            raise ValueError("confirm_external_calls is valid only for fresh replay")
        return self


class RecordedObservation(BaseModel):
    ref_id: str
    kind: Literal["model", "tool", "subagent"]
    request_hash: str
    output_ref: str
    output_hash: str


class ReplayResult(BaseModel):
    replay_id: str
    source_run_id: str
    replay_run_id: str
    mode: ReplayMode
    status: RunStatus
    stop_reason: StopReason
    artifact_refs: tuple[str, ...]
    diff_artifact_ref: str
```

- [ ] **Step 4: Implement catalog validation**

Catalog reads the source Checkpoint and only events whose `AgentEvent.sequence_no > CheckpointEnvelope.event_sequence_no`. `checkpoint_sequence_no` is never used as an Event cursor. It resolves every `ModelRequested`, `ToolStarted`, and `SubagentStarted` to a matching completion/output Artifact. Missing or hash-mismatched dependencies return sorted refs and block Recorded Replay.

`RecordedReplayEngine.run()`:

```text

class DiffItem(BaseModel):
    source_ref: str | None = None
    replay_ref: str | None = None
    comparison: str
    public_explanation: str
    metrics: dict = Field(default_factory=dict)


class DiffSection(BaseModel):
    section_id: str
    changed: bool
    items: tuple[DiffItem, ...]


class ReplayDiff(BaseModel):
    source_run_id: str
    replay_run_id: str
    replay_mode: ReplayMode
    sections: dict[str, DiffSection]
    generated_at: datetime
```

For deterministic artifacts compare SHA-256. For model text compare output Schema validity, citation/evidence IDs, forbidden claims, Gate decisions, StopReason and configured quality metrics; do not require byte equality. Every item records `source_ref`, `replay_ref`, comparison, and public explanation.
