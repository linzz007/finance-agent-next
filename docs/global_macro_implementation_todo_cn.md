## 已确认的产品目标

- 解释全球市场变化，不以持仓盈亏、交易建议为目标。历史持仓不视为当前持仓。
- 黄金、白银采用国际现货美元/盎司口径；主要美股指数不以 ETF 替代。
- 默认复盘各市场最近一个完整交易日；明确区分行情日期、新闻窗口、采集时间。
- 报告按市场概览、1–3 条宏观主线、可能影响及反证、后续关注、来源附录组织。
- 普通聊天能获取并分析数据；明确要求报告或 `/report` 才发布 HTML。两者共用证据和计算。
- 核心行情缺失、过期、分析校验失败不发布假成功报告；备用源不得偷偷变换品种或口径。

## 分工与验收原则

前四个子智能体分别负责采集、请求/指标契约、展示/Prompt、独立验收。中断恢复后增加第五个只读最终审核者；本轮总数不超过用户规定的五个。主执行者负责集成、路由、质量门控和真实运行。

验收分清录制/模拟测试与实时数据、真实模型测试。测试通过不能替代数据源时效验证。外部源不可用时记录问题，不编造数值、不改系统日期、不用期货或 ETF 代替现货，不声称全量金融数据覆盖。

数据 API 若需付费凭证，列为明确依赖，不擅自购买。普通查询和报告共用的分析输入、输出、权限与状态均需能在 Trace 中核对。

## 真实验收发现的问题

- 首轮 M01 将“今天行情”和“近一周宏观资料”的时间混合，严格交易日覆盖校验拒绝结果。已分离这两个时间窗口，并验证周报告截止日尚未收盘的边界。失败轮的M02/M03没有有效前序，不能算通过。
- 金银源是 BullionVault 现货中间参考价，按 UTC 完整采样参考日汇总，不是统一官方收盘价；报告保留原始品种、单位换算、采样证据和口径说明。恒定携带日不得假称新交易日。
- 首轮结果保存在本地 `data/acceptance/global-macro-acceptance.json`；源探测证据在 `docs/acceptance/global_finance_source_probe.md`。这些不代表最终功能验收完成。
- 真实复测修复：单资产请求被画像关注范围误拒、没有链接却称已附来源、合法金银链接被宏观来源列表误拒、英文引文句首大小写误拒、无效候选超预算继续重试。
- 内容复核已加强：指数分歧不能排除共同冲击；追问原因先回读analysis；工具层分开原始feed字段、适配器分类、本系统等待缓冲。最终回答仍有M03/M05/M06残余问题，不代表彻底修复。
- 后台Worker已按60分钟恢复运行，只采集公开资料与行情快照，不定时调用LLM、不自动发报告；电脑休眠/进程退出时不会持续运行。
