- 历史上的 `delegate_failed` 本轮没有复现。主 Agent 没有调用 subagent，而是选择直接读取 42/66 篇文章并完成画像交付。

### Q21：黄金、白银、纳指走势与作者解释

## 4. 问题归因

### 已确认的代码问题：已修复

Trace 的 `tool_summary.failed_calls` 之前只读取 `ToolCallRecord.status`。金融 Runtime 在模型参数校验失败时，会保留调用记录并另外写入 `tool_result(status=failed)`；因此一次真实失败可能被汇总为 0。现在汇总同时读取失败的 `tool_result`，按 `tool_call_id` 去重。离线回归结果：11 passed，2 skipped。

### 已确认的模型行为问题：尚未放宽契约

DeepSeek 在本轮仍会生成嵌套 `arguments`、旧字段名或旧版本 checkpoint 字段。当前契约已经明确要求：工具参数必须放在单层 `arguments`，并且必须匹配 `tool.describe` 返回的 schema。Runtime 拒绝非法参数是必要的安全边界；不能为了提高“成功调用率”而静默接受任意字段。

后续可以单独研究三种改进，但本轮不预先改变语义：

1. 在工具错误反馈中加入更明确的单层参数和“禁止旧字段”提示；
2. 对没有语义歧义的格式包装做兼容层，但仍在正式 schema 校验后执行；
3. 用模型稳定性测试统计每类工具的首次合法调用率、修正成功率和重复失败率。

### 已确认的环境/来源问题：不应归为代码错误

Q21 的部分外部事实没有可用的一手证据，Q28 的公众号原始页面被验证页拦截。这些情况应在答案中披露为 `inconclusive` 或来源限制；不应放宽允许域名、把搜索摘要当正文，或把作者观点改写成已验证事实。
