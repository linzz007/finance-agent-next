## 2. 修复内容

1. **历史范围**：短窗口仍使用 BullionVault 四小时采样；月度等较长窗口使用该来源季度历史的十二小时采样。整条序列同一口径，完整日汇总，不插值、不拼接、不用期货代替现货。
2. **完整性与缓存**：基准缺失、中间采样日期缺失等仍会阻断；严格查询不能复用未通过质量校验的缓存。
3. **修复反馈**：模型同时漏原文引文、违反数值格式时，一次返回全部独立校验错误，避免两次尝试分别撞上一个错误。
4. **追问权限**：“不重新获取”“不联网”“不再刷新”等在工具层拒绝重新采集，不能由模型改写 query 绕过。
5. **数字核查**：工具明确区分累计涨跌与单日涨跌；复核获得完整逐日涨跌记录。对明确的“日期 + 单日百分比”增加窄范围确定性检查，防止把累计涨幅误写为单日涨幅。它不是任意金融自然语言的完备验证器。
6. **口径核查**：询问采样、品种或截点时必须读取本报告的 instruments，不能把支持的默认采样配置当作本次实际配置。
7. **复核误判**：明确区分最大回撤与相对期前基准的最低跌幅，避免复核模型将正确的口径差异判错。
8. **页面状态**：对话结束后重新渲染工作空间控件，成功或失败均应解除禁用。
