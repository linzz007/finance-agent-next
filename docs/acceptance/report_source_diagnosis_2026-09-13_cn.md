# Report 数据源与匹配链路诊断记录

日期：2026-09-13

## 1. 本次问题

用户 query：

```text
/report 只看最近90天正式发布、与金融数据、投研、金融信息服务有关的数据治理官方政策；不用新闻报道冒充政策原文，最多3条。
```

旧表现是 HTML 报告没有有效数据，默认企业报告也容易混入 Agent 技术内容。这个问题不是“同花顺企业研判需求不存在”，而是数据源、画像主题和模型规划边界同时存在偏差。

## 5. 结论

严格政策 query 之前空报告不是正常结果，属于源覆盖、Wiki 默认主题和模型规划边界的问题叠加。修复后：

- 严格政策模式会只使用政策原文，排除新闻报道、征求意见稿和非政策更新。
- 企业报告会基于 THS Wiki 做业务关联，不再默认变成 Agent 自进化报告。
- 如果时间窗口内确实没有足够强证据，系统会生成带原因的诊断型报告，而不是空路径或硬凑低质量来源。

剩余边界：当前系统是“配置化多源探查”，不是法律意义上的全网穷尽检索；关键结论仍以已接入的 L1/L2/L3 源和 Wiki 事实为准。
