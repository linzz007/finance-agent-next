## 本次UI复核中发现的问题

- 刷新后工作空间选择丢失：补了ID持久化和浏览器存储不可用的降级测试。
- Trace把确定性运行时动作计为模型调用：已区分真实供应方请求；API新增字段并注明旧计数的事件口径。
- 子任务上下文是委派artifact引用而非普通visible_fields：已读取嵌套Manifest，展示可见块、委派引用及步骤/模型/时间预算。
- Wiki详情曾在0事实页面下展示全空间事实数：已改为本页事实与本页重点数。

新增组件的自动化验证使用`tests/test_workbench_wiki_ui.mjs`及Trace专项Node测试；最终数量见本轮回归结果，不在这里写易过期的固定数字。

## 人工验收标准

1. 不混用户身份，数据能新建、修改、搜索、回读。
2. 输入框可编辑、命令不误触发，模型状态明确。
3. 子任务与报告的真实执行记录能展开，不能用假进度或统计掩盖失败。
4. 报告能从对话打开，看到中文摘要、具体影响、建议及来源附录。
5. 无关键控件重叠、横向整页溢出或空白主内容。

本轮可以评价为功能可用性检查，不宣称已获“大厂设计师水平”认证。
