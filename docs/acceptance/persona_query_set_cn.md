# 32 条中文用户测试集

先录入 Wiki，再按照下列顺序测试。相同 persona/session 必须在同一会话；不同 session 新建对话。

这是一组功能验收，不是准确率 benchmark；每条既看答案，也看副作用和 Trace。

当前验收表采用逐例最新复测证据，不是最后一次代码修订后单次32条全跑。每条回答和Trace均标注原始批次、空间和会话。

## 同花顺 AI 研发研判（验收画像）

空间标识：`accept_20260910_release_ths`。

- ths_identity：验收角色：站在同花顺AI产品和研发人员角度了解技术变化；这是一份测试画像，不代表已接入同花顺内部系统、生产数据或内部技术栈。
- ths_goal：测试需求：评估公开金融资料问答和只读报表Agent原型，关注资料出处、检索准确性、工具权限、Trace可观测与可验证的回答。
- ths_stack：测试原型技术栈为Python、SQLite和LLM API；该技术栈仅属于本验收原型，不是同花顺生产架构事实。
- ths_constraints：只读分析，不执行交易、不访问生产系统、不向外部系统写数据。所有收益和合规判断必须注明条件，不得推测公司采用状态或经营指标。
- ths_watchlist：关注Agent Runtime、工具调用、检索、Trace、Eval；默认最近7天最多5条，优先官方发布及开源仓库Release，行业新闻只作线索，政策以官方原文为准。
## 个人 AI 工程师（验收画像）

- personal_identity：我是个人AI工程师，学习和实现信息分析Agent；不是金融企业，没有金融产品，不需要问财或iFinD的建议。
