# 验收 Query 选择边界

日期：2026-10-19  
状态：已实现，未启动付费验收

## 背景

冻结的金融验收文档包含 30 条 Query，但原有真实验收脚本只返回并允许选择
Q04、Q08、Q14。三题适合作为固定诊断批次，不能被称作完整 1.0 测试集。

## 变更

- `load_cases()` 现在校验并返回按 `Q01` 到 `Q30` 排序的完整冻结集合。
- 默认运行仍只选择 Q04、Q08、Q14，保留既有成本与诊断行为。
- `--cases Q01 Q02` 可以显式选择任意冻结 Query。
- `--all-cases` 才会显式选择全部 30 条 Query，不能与 `--cases` 混用。
- `manifest.json` 记录 `case_selection`，区分完整集合与诊断/显式批次。

本变更只修正验收工具的范围表达，不改变业务 Query、模型策略、预算或自动评分；
也不会自动启动付费调用。完整 30 题仍需单独授权并采用新的 `--output` 批次目录。
