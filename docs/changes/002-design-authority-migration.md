## 5. 来源缺损与尚未批准的事项

1. 飞书第十一节后的原始 Markdown 第 524-563 行有 37 行连续问号。这些不是终端显示乱码：同版本导出中已是问号。本轮原样保存，不根据上下文猜出原句。十二至十四章覆盖了许多同主题内容，但不能证明损坏段落没有新增要求；若用户记得独有技术点，可在共同复核时补回。
2. 原画板包含“专家分析方法 Skills”“公众号文章自动获取”等早期想法。保留在图和原始节点；不把图上的“正在实现”当成现今已完成。是否纳入下一轮、输入输出与验收如何定义，仍需确认。
3. 新项目多人使用范围、并发目标、部署环境、服务指标、任务取消/恢复、队列与事务设计尚未选定。迁移不预先选择 Redis、PostgreSQL 或某个框架，也不把本地 SQLite 换掉。
4. 产品目标和规范化架构是共同复核的第一版；明确引用既有确认内容，但新增组织和措辞仍需用户审核。后续实现任务需另外明确范围，不把“同意文档结构”当作“同意所有代码重构”。
