# 110 投研工作台 UI/UX

日期：2026-10-28。用户授权根据 `G:/edge/DESIGN.md` 直接实现，工作台适配要求优先于官网展示规则。

## 范围

H2 只有一个实际研究页面 `/workbench`，研究记录和测试归档共用它。
保留现有技术栈：静态 HTML/CSS/JavaScript、Lucide、Marked、DOMPurify 与 FastAPI。
不调整模型、预算、Agent 策略、队列、研究契约和数据库。

## 页面

统一暖米白背景 #F3F0EE、纸白面板 #FCFBFA、墨黑 #141413、次要灰 #696969。
橙色 #F37338 只作选择与品牌细节；成功、错误、进行中使用独立语义和文字。
中文无衬线正文 15px、等宽数字、零字距；胶囊用于命令与标签，报告与表格保持规整。

左侧提供品牌、新研究、记录类型、记录过滤和历史；中部提供模型、当前任务、完整报告、目录与导出。
右侧提供可收起的执行详情，包括真实任务统计、任务树、调用/事件 Trace 和来源读取入口。
手机端导航和执行详情使用互斥抽屉，Escape、遮罩和关闭按钮可收起，抽屉约束键盘焦点。
旧记录保持只读，并明确 Root 交付不代表子任务全部通过。

报告按原 Markdown 渲染，不通过新模型改写关键结论。目录来自原报告标题，导出来自原答案。
来源入口仅列来源工具的真实完成/失败记录；材料内容按现有 Artifact 授权接口读取。
Artifact 阅读器区分可读正文与原始数据，保留分页和错误反馈；未读全文时不冒充完整内容。
执行过程图只展示实际任务/调用分布，不添加行情、收益或虚构研究数据。

## 状态与边界

覆盖加载、空列表、无搜索结果、无报告、执行中、交付、失败、部分完成、资料读取失败和重试。
提交失败沿用原 request_id，重试不会自动创建额外模型运行；界面读取重试只重发读取请求。
切换会话必须重置旧任务统计、来源、目录与状态；归档分页保持原事件号和完整数量。
支持桌面三栏、平板双栏与手机单栏，正文、表格、长标识和弹窗不能撑破视口。
不在全屏阅读中自动滚动到报告末尾；仅用户接近末尾的进行中更新可跟随。

浏览器在真实历史记录中检查报告、来源、任务失败和 Trace，并走通真实输入到最终报告的研究流程。
检查桌面与手机的文字、导航、抽屉、表格与弹窗；记录实际结果与模型调用次数。
