# Research Plan skill

`research.plan` 是每轮研究都使用的 Todo 插件，用于保持用户目标、范围、进度、验证检查点和阻塞原因。简单问题也创建一份简洁但完整的短计划；复杂问题再按实际目标拆分。计划不规定文章读取、分析方式、验证工具或 Subagent 使用顺序；主 Agent 仍自主决定具体做法。计划的完成条件必须包含“已完成验证判断，或明确记录了为什么某些内容不需要外部验证以及仍有哪些缺口”。

计划状态写入当前 `session_id/run_id` 的受控运行目录，后续只能通过授权的 `load` 读取，不能让模型直接传入任意文件路径。最终答案交付状态由 Runtime 独立记录，主 Agent 不能把交付目标直接标记为完成；模型错误、工具失败或门控阻塞时，交付目标保持 `blocked`。

计划中的最后一项目标是 Runtime 的 `runtime_delivery` 保留项，不是研究任务；主 Agent 不应更新它。提交满足门控的最终答案后，Runtime 会自动把它标记为 `done`；若本轮没有发布答案，则标记为 `blocked`。
