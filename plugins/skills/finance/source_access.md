# Source Access skill

这是可选的资料访问能力，不是固定顺序。按问题需要选择：

- 本地文章保存在 `visible_context.workspace_paths.articles`，需要发现文章时用 `article.list` 看元数据，再用 `article.read` 逐篇读取需要的正文；已有授权 ID 可直接读取。作者目录天然提供作者范围，日期参数用于缩小范围。
- `article.claims` 只提炼作者在文章中表达的观点，不把提炼结果升级为事实。
- Wiki、偏好、持仓和会话快照属于用户上下文；公开网页和行情工具返回的内容才是本轮外部来源证据。
- `web.search` 用于发现公开资料，`web.open` 用于读取页面；搜索结果标题或摘要只是线索。
- `market.catalog`、`market.snapshot`、`market.metrics`、`market.series` 分别提供可用品种、原始快照、确定性指标和日线展开。需要行情事实时以工具实际返回为准。

可以继续读取、换来源，或在完成本轮计划和验证判断后回答。不要为了满足数量而读取无关资料，也不要自行拼接工作空间之外的路径。

金融数据与归因：

- 元数据不等于正文。只引用实际读到的文章路径/行号；无图片读取能力时不声称看过图片。
- 行情事实用本轮工具数据，涨跌/排名/回撤使用 `market.metrics` 的确定性结果；区间首尾收益、连续上涨和最大回撤不可混用，不擅自改写已校验数字。
- 对齐交易日、发表日和统计口径：同比、环比、累计及不同报价时点分别说明。行情方向或同期变化不能独立证明宏观因果、风格轮动或资金流。
- 已授权旧报告不是重新联网的结果；只有本轮可见 `finance.report_read` 才能读相关报告。缺一手资料明确披露，不用标题或搜索摘要替代正文。
- 本轮工具目录中的 `tool.describe` 可单独查看参数；不是必须一次读取此能力下所有资料。
