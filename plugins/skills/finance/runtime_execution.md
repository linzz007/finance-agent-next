# Finance Runtime Execution skill

历史兼容说明：变更 010 后，本模块退出金融主配置；现行原则在主 Prompt，来源/口径规则在 `source_access.md`，验证规则在 `evidence_review.md`。保留本文件供历史引用，不作为现行入口。

这是金融研究的可选执行能力，不规定固定工作流。主 Agent 根据问题和可见证据自主选择读取、计算、报告追问和 Subagent。

- 本地文章按作者文件夹浏览：先用 `article.list` 获取作者和日期范围内的元数据，再用 `article.read` 逐篇读取正文。文章标题、摘要和作者说法是观点来源，不能直接当作外部事实。
- 只把本轮实际 `article.read` 返回的路径和行号用于作者归因；不要把只出现在元数据中的文章当成已读。`article.claims` 只提炼已选文章观点，提炼结果不是独立核验事实。
- 需要独立查证时，用 `web.search` 发现资料并用 `web.open` 读取正文，或使用实际返回的行情/政策证据；搜索摘要和官方 feed 条目不能替代正文。没有一手来源时，明确说明尚未独立核实。
- 多篇文章分析时保持“已列出”和“已读正文”的区别。委派 analyst 只能读取 Runtime 分配的精确 article_id，不得把一个批次当成未分配文章的覆盖；主 Agent 保留跨批次综合。
- 对作者文章的关键判断应在正文附近给出完整路径和行号，例如 `TT/articles/13.md:L13`。不要发明价格、日期、来源链接或未读取的图片内容，并保留不确定性和反证。
- 行情问题应通过实际行情工具获取数据，不凭模型记忆编造行情。普通行情不自动生成 HTML；历史报告追问只能用已授权的 `finance.report_read`，不能把旧报告当作重新联网结果。
- 使用 `market.metrics` 的确定性统计判断涨跌排名、连续上涨和最大回撤，不自行心算。区间首尾涨跌只由固定基准和期末价格决定，中途反弹不改变首尾收益；连续上涨不能跨过下跌日；最大回撤不等于相对期前基准最低跌幅。
- 不同指数方向、涨幅差异或窄幅波动不能证明不存在共同宏观驱动；没有板块、成分或资金流证据时，风格轮动只能作为待验证假设。资料缺失不能写成价格变化原因。
- 宏观数据逐项保留统计口径：当月同比、环比和年内累计不能统称为累计；标题中的观察期提示不能覆盖正文中其他数字。没有展开原文时，只陈述标题明确的信息。
- 工具成功返回结构化分析后，优先使用其中的价格、路径、假设、证据缺口和来源，不重复读取相同日线或自由改写已校验数字；追问时按需展开证据。
- 用户明确要求 Subagent 时，先获取本轮需要的资料，再由主 Agent 选择 `analyst`、`skeptic` 或 `verifier`；委派结果必须回到主 Agent 综合。子智能体的同源复核不能称为独立交叉核价。
- 最终回答直接回应用户问题，区分市场事实、作者/机构观点、模型推断和待验证内容；不为了凑主题或段落制造因果解释。
