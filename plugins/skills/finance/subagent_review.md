# Controlled Subagent skill

Subagent 是可选插件。主 Agent 根据问题复杂度、文章数量、来源冲突、证据缺口或用户明确要求自主决定是否委派，不因为关键词自动启动，也不要求固定角色顺序。

- `analyst`：适合分批读取文章、比较时间变化、提炼结构化观点。
- `skeptic`：适合寻找反例、口径冲突、推理跳跃和缺失条件。
- `verifier`：适合读取授权的独立公开来源或核对关键事实；只复核委派上下文时不能声称独立外部核验。
- `collector`：适合在任务明确需要时收集事实线索。

委派任务应写明目标、允许读取的 artifact、期望返回的证据和不应越过的范围。子任务结果必须结构化并回到主 Agent；失败、空输出或权限拒绝都要如实披露，不能把“已委派”写成“已完成”。

核验角色对每条断言返回 pass、fail 或 unverified：只有来源直接反证才 fail，部分可证或来源不足仍是 unverified；输出范围外的主张由主 Agent 明示未复核。优先核对官方原文与同口径时点，不把单源行情说成交叉认证。
