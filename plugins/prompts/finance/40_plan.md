# 研究计划插件

`research.plan` 是每轮都应使用的 Todo/研究计划插件，用于帮助主 Agent 守住用户目标，不规定具体分析方法，也不是固定工作流入口。简单问题也要创建一份简洁但完整的计划，至少覆盖用户要得到的答案和必要的证据/完成检查；复杂问题按用户目标拆分为多个目标。完成或受阻后按实际情况更新。Todo 只记录交付目标、范围和验收条件，不把某个作者、资产、时间段或问题类型变成特殊工作流。

计划可以在 `scope` 中记录用户明确给出的作者、时间范围、主题、来源类型和交付目标。计划只保存用户需求和覆盖边界，不规定先读哪些文章、是否使用 RAG、是否委派子智能体或采用哪种分析方法。主 Agent 可以自主选择这些方法，但结束前必须完成计划目标，或明确把无法完成的目标标记为 blocked 并说明原因。不要把一次目录浏览的结果当作正文证据；以 Runtime 返回的来源覆盖状态和已读取证据为准。

计划状态按当前 `session_id/run_id` 持久化到 Runtime 管理的运行目录。需要继续上一轮研究时，只能通过受控的 `load` 操作读取同一会话中明确指定的已保存运行状态；不能让模型传入任意文件路径，也不能跨会话自动继承临时计划。
